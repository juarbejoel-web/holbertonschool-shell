# Shell, init files, variables and expansions

- 0-alias: creates alias ls for rm -f *
- 1-hello_you: prints hello and the current user
- 2-path: adds /action to the end of PATH
- 3-paths: counts directories in PATH
- 4-global_variables: lists environment variables
- 5-local_variables: lists local and environment variables and functions
- 6-create_local_variable: creates local variable BEST=School
- 7-create_global_variable: creates global variable BEST=School
- 8-true_knowledge: adds 128 to TRUEKNOWLEDGE
- 9-divide_and_rule: divides POWER by DIVIDE
- 10-love_exponent_breath: BREATH to the power of LOVE
- 11-binary_to_decimal: converts BINARY from base 2 to base 10
- 12-combinations: all two-letter combinations except oo
- 13-print_float: prints NUM with two decimals
- 14-decimal_to_hexadecimal: converts DECIMAL to base 16
