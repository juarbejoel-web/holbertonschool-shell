# Shell Basics

- 0-current_working_directory: prints the absolute path of the current directory
- 1-listit: lists the contents of the current directory
- 2-bring_me_home: changes the working directory to the home directory
- 3-listfiles: lists directory contents in long format
- 4-listmorefiles: lists contents including hidden files in long format
- 5-listfilesdigitonly: long format with numeric user and group IDs including hidden files
- 6-firstdirectory: creates /tmp/my_first_directory
- 7-movethatfile: moves /tmp/betty into /tmp/my_first_directory
- 8-firstdelete: deletes /tmp/my_first_directory/betty
- 9-firstdirdeletion: deletes the directory /tmp/my_first_directory
- 10-back: changes to the previous working directory
- 11-lists: lists all files in the current dir, parent dir and /boot in long format
- 12-file_type: prints the type of /tmp/iamafile
- 13-symbolic_link: creates a symbolic link __ls__ pointing to /bin/ls
- 14-copy_html: copies HTML files to the parent dir if missing there or newer
- 15-lets_move: moves files starting with an uppercase letter to /tmp/u
- 16-clean_emacs: deletes files ending with ~
- 17-tree: creates the directories welcome/to/school
